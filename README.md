
# Projeto Final: Carteira de Investimentos Digitais

## 1. Descrição do Projeto

O projeto consiste no desenvolvimento de um sistema de controle de carteira de investimentos, executado diretamente no terminal. A aplicação tem como objetivo permitir que os usuários cadastrem, organizem e acompanhem seus investimentos, oferecendo funcionalidades como consulta de ativos, cálculo de rentabilidade, ordenação dos investimentos por desempenho e armazenamento dos dados em arquivos de texto. O objetivo é oferecer uma ferramenta simples e acessível para pessoas que desejam conhecer melhor o funcionamento dos investimentos, alinhando-se ao Objetivo de Desenvolvimento Sustentável (ODS 8.10) da ONU.
